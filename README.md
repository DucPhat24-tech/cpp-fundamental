# C++ Fundamentals & Data Structures Practice

Repository lưu trữ quá trình tự học C++, thư viện chuẩn STL và luyện tập Cấu trúc dữ liệu & Giải thuật (DSA).

## Folder Structure
- `01-28tech-basic/`: Basic syntax, loops, functions, and number theory exercises.
- `02-arrays-vectors/`: 1D/2D arrays, C++ STL `vector`, prefix sums, and two pointers.
- `03-strings-stl/`: String manipulation and STL containers (`map`, `set`, `stack`, `queue`).
- `04-recursion-sorting/`: Recursion, sorting algorithms, and binary search.
- `05-leetcode-dsa/`: Solutions to LeetCode problems with time/space complexity notes.
- `06-mini-projects/`: Console applications and file-handling exercises.
